# ColorChase

Jogo 2D em Unity, feito com auxílio de IA.

O projeto está no início. Por enquanto o repositório tem apenas a configuração base do Unity: a cena inicial com câmera e luz global 2D, o pipeline URP 2D e o Input System. Ainda não há scripts de gameplay.

## Tecnologias

- Unity 6 (`6000.4.8f1`)
- Universal Render Pipeline (URP) com o Renderer 2D
- Input System
- Pacotes 2D do Unity (Sprite, Tilemap, Animation e SpriteShape)

## Como rodar

1. Instale o Unity `6000.4.8f1` pelo Unity Hub.
2. No Unity Hub, clique em **Add** e selecione a pasta do repositório.
3. Abra a cena `Assets/Scenes/SampleScene.unity` e aperte Play.
